Sobre mí

// quién soy

Soy QA Analyst en Bitlogic S.A., donde trabajo en un proyecto para la Universidad Siglo 21. Mi día a día combina testing manual con automatización end-to-end usando Playwright, Cucumber y Page Object Model.

Estoy terminando Ingeniería en Software en la Universidad Siglo 21. En la carrera me interesaron especialmente la calidad de software, la verificación formal y el diseño de sistemas, y eso se nota en cómo encaro el testing: entender bien qué debería pasar antes de comprobar si pasa.

Trabajo con metodología Shape Up, gestiono casos en QA Touch y el seguimiento en Linear.

Torba

Trabajo Final de Graduación

Prototipo de sistema de orientación por consultas de voz para estudiantes con discapacidad visual. El estudiante acerca el celular a una etiqueta NFC ubicada en el campus y el sistema le responde por voz dónde está y cómo llegar a donde necesita.

  • Diseño centrado en accesibilidad: la interacción no depende de la pantalla.
  • Activación por etiquetas NFC distribuidas en puntos clave del edificio.
  • Consultas en lenguaje natural con respuesta hablada.

Sistema de torneos FACHSC

Seminario de Práctica

Sistema de gestión de torneos de hockey para la federación FACHSC: equipos, fixture, resultados y documentación oficial de cada partido.

  • API REST con Spring Boot y PostgreSQL; frontend en React + TypeScript con Vite.
  • Generación del acta de partido como PDF A4 listo para imprimir.
  • Entorno de desarrollo con Docker; resolví conflictos de puertos, procesamiento de Lombok y compatibilidad de versiones fijando Java 17.

QA Automation Demo

Automatización E2E

Framework de pruebas end-to-end con BDD sobre un sitio de práctica público. Muestra la estructura con la que trabajo: escenarios en Gherkin legibles para todo el equipo y Page Objects que separan el "qué" del "cómo".

  • Escenarios en español con Gherkin (login, carrito, checkout).
